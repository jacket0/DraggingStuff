# Модели слизи

Куски липкой слизи для главы 7 (EighthLevel). Форму собирает код по соседним слотам, цвет, блик и толщину задаёт шейдер `Custom/SlimeJelly` (материалы `SlimeSpot`, `SlimeForecast`).

## Файлы

| Файл | Что это |
|---|---|
| `build_slime.py` | Параметрический скрипт. Строит все куски, экспортирует FBX и сохраняет `Slime.blend` |
| `Slime.blend` | Сохранённый результат, куски стоят в ряд для просмотра |
| `Assets/Models/Slime/*.fbx` | Экспорт |

## Куски

Начало координат у каждого на полу в центре, плоское основание на нуле, лужа лежит на плоскости XZ в Unity.

| Модель | Размер (X x Z x Y), м | Где используется |
|---|---|---|
| `SlimePuddle` | 0.37 x 0.28 x 0.03 | лужа в слоте, пятна источника |
| `SlimePuddleWall` | 0.36 x 0.26 x 0.15 | лужа у боковой стенки полки с налётом и потёками, для крайних слотов (зеркалится в коде) |
| `SlimeBridge` | 0.15 x 0.22 x 0.025 | перемычка между соседними слотами полки |
| `SlimeForecastPuddle` | 0.095 x 0.06 x 0.012 | лужица прогноза |

Стенка в `SlimePuddleWall` на локальном -X.

## Как обновить

1. Открыть `Slime.blend`, запустить `build_slime.py` во вкладке Scripting. Скрипт пересоберёт куски и перезапишет FBX.
2. В Unity: `Tools/Slime/Setup Visuals`, он соберёт префабы, материалы и источник.
