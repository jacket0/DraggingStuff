# Модель пятна слизи

Пятно липкой слизи для главы 7 (EighthLevel). Лаймовый полупрозрачный материал, блик и колыхание живут в Unity (`SlimeSpot.prefab`, шейдер `Custom/SlimeJelly`).

## Файлы

| Файл | Что это |
|---|---|
| `build_slime.py` | Параметрический скрипт. Главный источник модели, сразу экспортирует FBX и сохраняет `Slime.blend` |
| `Slime.blend` | Сохранённый результат |
| `Assets/Models/Slime/SlimeBlob.fbx` | Экспорт |

## Состав и размеры

- Одна сетка `SlimeBlob`, 1800 треугольников, один материал.
- Начало координат в центре основания, пятно лежит на плоскости XZ (в Blender XY). Размер 0.286 x 0.24 x 0.121 м, плоское основание на нуле, под колонку полки.
- Форма: плоская лужа, купол, четыре языка по краям, гребень сверху, две капли. Сплавлено воксельным ремешем и сглажено.

## Как обновить

1. Открыть `Slime.blend`, запустить `build_slime.py` во вкладке Scripting. Скрипт пересоберёт пятно и перезапишет FBX.
2. В Unity: `Tools/Slime/Setup Visuals`, он заменит сетку в префабе и настроит материалы.
