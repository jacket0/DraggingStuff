# Модель ключа

Ключ для сейфов главы 5 (SixthLevel). Тёмный металл, свечение и анимация живут в Unity (`ShelfKey.prefab`, `ShelfKeyView`).

## Файлы

| Файл | Что это |
|---|---|
| `build_shelf_key.py` | Параметрический скрипт. Главный источник модели, сразу экспортирует FBX |
| `ShelfKey.blend` | Сохранённый результат |
| `Assets/Models/Keys/ShelfKey.fbx` | Экспорт |

## Состав и размеры

- Одна сетка `ShelfKey`, 1152 треугольника, один материал.
- Начало координат на кончике стержня, ключ стоит вдоль оси Z (в Unity вдоль Y). Высота 0.225 м, ширина по кольцу 0.11 м.
- Кольцо: тор с отверстием около 0.058 м. В отверстии стоит метка сейфа (`MarkPoint` в префабе, масштаб 0.5).
- Бородка из двух зубцов на стороне +X.

## Как обновить

1. Открыть `ShelfKey.blend`, запустить `build_shelf_key.py` во вкладке Scripting. Скрипт пересоберёт ключ и перезапишет FBX.
2. В Unity: `Tools/Key Locks/Setup Visuals`, он заменит сетку в префабе и настроит материал.
