# DraggingStuff (Сортировка дома)

Казуальная 3D-головоломка для Яндекс Игр (WebGL, горизонтальный экран 16:9). Игрок перетаскивает предметы между колонками полок и собирает одинаковые вместе, чтобы очистить шкаф.

## Геймплей

- Полка состоит из колонок, предметы в колонке стоят друг за другом. Двигать можно только передний предмет: в пустую колонку или обменом с передним предметом другой колонки.
- Когда передние предметы во всех колонках полки совпадают, они исчезают, а следующие выходят вперед. Так могут получаться каскады.
- Уровень пройден, когда доска пуста. За время прохождения дается от 1 до 3 звезд.

## Контент

Кампания из 25 уровней на время, 5 глав по 5 уровней. Каждая глава вводит свою механику:

| Глава | Уровни | Механика |
|---|---|---|
| 1. Первая уборка | 1-5 | основа, обмен предметов |
| 2. Всему свое место | 6-10 | полка-фильтр |
| 3. Пыльные полки | 11-15 | закрытые полки |
| 4. Цех игрушек | 16-20 | конвейеры |
| 5. Хранилище | 21-25 | ключи и сейфы |

Еще в игре есть бесконечный режим с лидербордом, комбо-множитель очков, бонусы (подсказка, заморозка комбо) и обучающий уровень. Языки: русский, английский, турецкий.

Раскладки уровней генерируются заранее в редакторе, и солвер проверяет, что каждая проходима. В игре выбирается один из сохраненных проверенных вариантов.

## Стек

- Unity 2022.3.62f2, встроенный рендер, сборка WebGL
- PluginYourGames (YG2): SDK Яндекс Игр, реклама, лидерборды, облачные сохранения
- uGUI, TextMeshPro, DOTween
- Git LFS для бинарных ассетов

## Запуск

1. Установите [Git LFS](https://git-lfs.com) и клонируйте репозиторий.
2. Откройте проект в Unity 2022.3.62f2.
3. Запускайте игру со сцены `Assets/Scenes/Startup.unity`.

Генерация и проверка уровней находятся в меню редактора **Tools > Timed Levels** (`Generate All Variants`, `Validate Campaign`, `Validate Gameplay Changes` и другие).

## Структура

```
Assets/Scripts/   код игры: модель полок и ходов, сессии уровней, механики глав, UI, платформа
Assets/Editor/    генератор раскладок, солвер, проверки уровней, сборка WebGL
Assets/Levels/    каталог глав и данные уровней
Assets/Scenes/    стартовая сцена, меню, сцены глав, бесконечный режим
docs/GDD.md       техническое описание механик, баланса и монетизации
```
