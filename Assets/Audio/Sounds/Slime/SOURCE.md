# Источники звуков слизи

| Файл | Источник | Лицензия | Обработка |
|---|---|---|---|
| `SlimeGrow.wav` | Синтезирован для проекта | Своё | Шум с плавно закрывающимся фильтром, низкий гул и четыре пузыря |
| `SlimeStuck.wav` | Синтезирован для проекта | Своё | Падающий тон с вибрато (тянущийся чмок) и короткий шум |
| `SlimeClean.wav` | Синтезирован для проекта | Своё | Щелчок-хлопок, шум брызг и четыре пузыря |
| `SlimeDry.wav` | Синтезирован для проекта | Своё | Длинный шум с затухающим фильтром, низкий тон и пять пузырей |
| `SlimeLoss.wav` | Синтезирован для проекта | Своё | Тяжёлый низкий «глоп» с шумом и пузырём |

Это временные звуки. Скрипт синтеза лежит в `.utmp/slime-audio/synth.py` рабочей папки. Звуки предзагружаются (Preload Audio Data), SFX-группа `MainAudioMixer`.
